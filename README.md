# Thingsboard Tester Program
Esta aplicação tem como finalidade realizar inserção de dados via MQTT à plataforma Thingsboard. Estou utilizando a versão Community do Thingsboard, que oferece o programa de forma open-source para ser implementada localmente ou dependendo de sua estrutura, atribuir à uma nuvem. 
Este programa necessita que você tenha a plataforma Thingsboard instalada dentro de seu computador e assim você possa utiliza-lo.

# Porque criei este programa ?
Esta ideia veio da necessidade de testar a comunicação via MQTT com um dispositivo externo, onde você pode construir uma estrutura de telemetria de dados simulada para criar e testar dashboards dentro da plataforma. Assim você pode economizar tempo em projetos sem a necessidade de um hardware que tenha que realizar a comunicação com a plataforma.
